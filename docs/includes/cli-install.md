=== ":material-linux: Linux / :material-apple: macOS"

    ```shell
    curl -fsSL https://kotl.in/install.sh | sh
    ```

    The installer script downloads the Kotlin CLI, places it in `~/.local/bin`, and ensures it's on your `PATH`.
    No `sudo` required.
    You can review [the installer script](https://kotl.in/install.sh) before running it.

=== ":material-microsoft-windows: Windows"

    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm 'https://kotl.in/install.ps1' | iex"
    ```

    The installer script downloads the Kotlin CLI, places it in `~/.local/bin`, and ensures it's on your `PATH`.
    No `sudo` required.
    You can review [the installer script](https://kotl.in/install.ps1) before running it.
