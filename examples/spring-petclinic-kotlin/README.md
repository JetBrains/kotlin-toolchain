# Spring Petclinic

This is the Kotlin Toolchain version of the
[Spring Petclinic (Kotlin)](https://github.com/spring-petclinic/spring-petclinic-kotlin) sample project.

Here are a few commands you can try to experiment with the Kotlin Toolchain CLI.

Compile the project:

```shell
./kotlin build
```

Run tests:

```shell
./kotlin test
```

Run the application:

```shell
./kotlin run
```

For more information about what you can do with the CLI, use:

```shell
./kotlin --help
```
