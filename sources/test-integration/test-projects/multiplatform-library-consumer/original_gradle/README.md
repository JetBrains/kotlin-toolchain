# Multiplatform library template

This Gradle multiplatform project was ported to Kotlin Toolchain
as a project [multiplatform-library-template-main](../multiplatform-library-template-main)

This projct could be used to get gold files used for the Kotlin Toolchain tests of
KMP publication. 

To generate original publication gold files, run `./gradlew publishToMavenLocal`
