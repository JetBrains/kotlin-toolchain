# Multiplatform library template

This Gradle multiplatform project was ported to Kotlin Toolchain as a project [multiplatform-library-template-main](..)

This project can be used to get gold files used for the Kotlin Toolchain tests of KMP publication. 

To generate original publication gold files, run `./gradlew publishToMavenLocal`.
